Developer Profile — HTML Project

A simple developer profile webpage built using HTML5. This is my first HTML project, created to practice the fundamental concepts of HTML and build a structured personal profile page.

📌 Project Overview

The webpage contains:

* Personal introduction
* About Me section
* Profile image
* Technical skills
* Learning roadmap
* Useful external links
* Study schedule

🛠️ Technologies Used

* HTML5

📚 HTML Concepts Practiced

This project helped me practice the following HTML concepts:

* HTML document structure
* <!DOCTYPE html>
* Headings — <h1> to <h6>
* Paragraphs — <p>
* Horizontal rule — <hr>
* Images — <img>
* Links — <a>
* Attributes such as src, alt, href, target, width, and height
* Unordered lists — <ul>
* List items — <li>
* Nested lists
* Tables — <table>
* Table rows — <tr>
* Table headers — <th>
* Table data — <td>
* Table sections — <thead> and <tbody>
* Table caption — <caption>
