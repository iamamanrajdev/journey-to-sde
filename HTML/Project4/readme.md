University Registration Form

A simple University Registration Form built using HTML5. This project was created to practice HTML forms, different input types, labels, attributes, and semantic HTML.

📌 Project Overview

The form allows a student to enter their:

* Personal details
* Contact information
* Academic information
* Extra-curricular activities
* Account details
* Terms & Conditions agreement

🛠️ Technologies Used

* HTML5

🚀 How to Run

1. Open the Project4 folder.
2. Open form.html in a modern web browser.
3. Fill out the registration form.
4. Click Register to submit the form.
5. Click Clear Form to reset the form.
